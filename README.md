# Call-Centre-Dashboard---Excel
Personal project: Call Centre Dashboard in Excel using pivot tables, formulas, and data visualization.

📊 Call Centre Dashboard (Excel Project)

This project showcases how Excel can be used to clean, analyze, and visualize business data effectively.
It simulates a Call Centre Performance Dashboard that tracks key metrics like total calls, revenue, duration, and customer ratings.

🧭 Project Overview

Using Microsoft Excel, I performed data cleaning, pivot-based aggregation, and KPI visualization to build a fully interactive dashboard.
The process included:

Structuring and formatting call data

Creating pivot tables to summarize performance

Designing dynamic charts for calls, revenue, and ratings

Comparing performance across cities and genders

🌟 Key Insights

1,000 total calls handled across all representatives and cities

Top-performing reps identified by call volume and revenue

Monthly and weekly call trends visualized with dynamic charts

Gender-based comparison showing caller distribution

Regional segmentation for deeper performance tracking
